uFawkesObs v1.0.0 shipped on 14 October 2026. It is a starter observability stack: Prometheus for metrics, Loki for logs, Tempo for traces, Grafana on top, and a small DORA service that turns deployment events into the five DORA metrics.

## What you get

- **Metrics, logs and traces** in one Grafana, wired together. A demo app emits all three, so you see data the first time you start it.
- **The five DORA metrics**: deployment frequency, lead time for changes, change failure rate, failed deployment recovery time and rework rate.
- **Deployment-event collectors** for GitHub Actions and Woodpecker CI, plus the ingestion API they post to.

## Try it

```bash
git clone https://github.com/paruff/uFawkesObs.git
cd uFawkesObs
cp .env.example .env   # set GRAFANA_ADMIN_USER and GRAFANA_ADMIN_PASSWORD
make init
make up-full
```

Grafana is on `localhost:3000`. It needs Docker with Compose v2 and about 4 GB of free RAM.
